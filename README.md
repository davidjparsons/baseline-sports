# Baseline Sports

Ad-free sports scores PWA using unofficial ESPN feeds.

## Deploy on GitHub Pages

1. Create a **public** repository named `baseline-sports`.
2. Upload the *contents* of this directory to the repository root (not the enclosing folder).
3. Go to **Settings → Pages** and choose **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
4. Visit `https://YOUR-USERNAME.github.io/baseline-sports/` (replace YOUR-USERNAME).
5. In Chrome on Android: menu ⋮ → **Add to Home screen** → **Install**.

App shell works offline after first load, but live scores require internet.
ESPN endpoints are unofficial and can change or impose restrictions. Some browsers may block cross-origin data requests.
